# Zee's Kitchen

A mobile-first food ordering experience for Zee's Comfort Kitchen.

## Product direction

Zee's Kitchen is designed around a simple conversion path:

**Social media → Menu → Cart → Order → Confirmation**

The first release will include:

- Premium mobile-first public storefront
- Menu categories and food cards
- Cart and checkout flow
- Customer order confirmation/tracking
- Business dashboard for orders
- Menu management
- Responsive design and strong accessibility

## Planned architecture

- Next.js + TypeScript
- Tailwind-free custom CSS for a distinctive visual system
- PostgreSQL for users, menu items, orders and business data
- API routes/server actions for application logic
- Object storage for food/profile media
- Payment integration after the ordering MVP is validated

## Build phases

1. Brand + storefront UI
2. Menu + cart
3. Checkout + order lifecycle
4. Admin dashboard
5. Database/API integration
6. Notifications and payments
7. Production hardening

## Design principles

- Mobile first
- Food photography is the visual hero
- Fast path to ordering
- Warm, premium, welcoming feel
- Clear 24/48-hour notice messaging
- Admin should be able to manage the business without a developer
